# 南京晓庄学院网络安全知识竞赛参考题库助手

这是针对南京晓庄学院网络安全知识竞赛参考题库的 Tampermonkey 用户脚本，内置 69 道参考题目，通过题干和选项文字匹配。

**仅在 [https://ks.wjx.com/vm/ep8c2Pw.aspx](https://ks.wjx.com/vm/ep8c2Pw.aspx) 页面生效**（包括该页面附带查询参数或片段的情况），不适用于其他问卷星页面。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. [安装用户脚本](https://github.com/DreamYuande/njxzc-cybersecurity-quiz-helper/raw/refs/heads/main/cybersecurity-quiz-helper.user.js)，并在扩展中确认安装。
3. 打开脚本指定的问卷星页面：`https://ks.wjx.com/vm/ep8c2Pw.aspx`。

## 使用

点击“仅检查”查看匹配结果；点击“一键填写”填写匹配的题目，也可随时停止。个人信息需要手动填写，提交前请自行核对题目和答案。脚本不会自动提交。

题库答案是参考答案，并非本场竞赛官方答案；第 43 题按照用户提供的更新题库设为 A、B、C。页面结构或题目变化可能影响匹配，请注意检查跳过或待检查的题目。
