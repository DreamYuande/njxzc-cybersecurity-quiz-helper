# 南京晓庄学院网络安全知识竞赛参考题库助手

这是针对南京晓庄学院网络安全知识竞赛参考题库的 Tampermonkey 用户脚本，内置 69 道参考题目，通过题干和选项文字匹配。支持保存基本信息、刷新后自动填写，以及按设置秒数自动提交。

**仅在 [https://ks.wjx.com/vm/ep8c2Pw.aspx](https://ks.wjx.com/vm/ep8c2Pw.aspx) 页面生效**（包括该页面附带查询参数或片段的情况），不适用于其他问卷星页面。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. [安装用户脚本](https://github.com/DreamYuande/njxzc-cybersecurity-quiz-helper/raw/refs/heads/main/cybersecurity-quiz-helper.user.js)，并在扩展中确认安装。
3. 打开脚本指定的问卷星页面：`https://ks.wjx.com/vm/ep8c2Pw.aspx`。

## 使用

1. 首次打开页面，在助手面板填写学工号、姓名，选择学院部门和身份。学院部门与身份选项来自当前页面。
2. 设置“刷新后自动作答”和“按设置秒数自动提交”两个开关。关闭自动提交后，刷新仍可自动填写，随后自行提交。
3. 在“提交用时”中填写秒数，范围为 0–3600，支持小数，默认为 10 秒。从本轮开始填写时计时：例如设为 10 秒，填写核对完成且满 10 秒后才会提交；设为 0 则核对完成后立即提交。若填写本身已超过设置用时，则在核对通过后提交。
4. 点击“保存设置”保存；点击“保存并作答”立即运行。以后刷新页面，脚本会读取已保存设置并按开关运行。两个开关默认开启，基本信息未填完整时不会自动运行；旧版保存的基本信息会继续保留，首次升级默认使用 10 秒。

各题同时启动填写，取消逐题和逐选项的固定等待，通过页面原有选项事件更新答案。实际完成时间取决于浏览器、页面加载和问卷星的响应。

开启自动提交时，填写完成后会显示剩余秒数。计时结束且基本信息、全部显示题目的答案再次核对通过后，脚本会点击页面的“提交”按钮，每次页面加载最多自动点击一次。出现未收录题目、选项变化、额外必填题或填写失败时会停止自动提交，并在面板显示原因。验证码、确认提示和服务器返回结果仍由页面处理；“已点击提交”不代表服务器已接收答卷。后台标签页的浏览器计时限制可能导致提交晚于设置时间。

“仅检查”可查看题库匹配情况；“停止”可中止填写或取消倒计时中的提交；“清除设置”可删除已保存的信息。关闭自动提交后，脚本只填写并核对。

设置保存在当前浏览器的该站点本地存储中，包含学工号和姓名。更换浏览器或清除站点数据后需要重新设置，请在自己的浏览器中使用。也可在源码的 `DEFAULT_SETTINGS` 中填写默认值，界面保存的设置优先；不要将个人信息提交到公开仓库。

内置答案仅供参考。页面结构或题目变化可能影响匹配，请检查跳过或待检查的题目，并在提交前核对答案。

## 验证

通过 JavaScript 语法检查、69 道题的 175 组乱序选项匹配校验，以及基于页面副本和模拟页面事件的 16 项场景测试，覆盖预填写、自动作答、提交计时、提交开关、停止、异常拦截和旧设置兼容。未向真实竞赛提交测试答卷。
